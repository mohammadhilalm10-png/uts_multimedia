# Teori Warna untuk Desain Digital

Presentasi web interaktif (14 slide) dibuat dengan HTML, CSS, dan JavaScript murni tanpa library.

## Topik
Model warna RGB, roda warna, skema harmoni, psikologi warna, kontras dan aksesibilitas (WCAG), aturan 60-30-10, tiga studi kasus (Facebook, McDonald's, Instagram), dan kuis.

## Fitur interaktif
- Mixer warna RGB (slide 4)
- Pengecek kontras WCAG (slide 8)
- Kuis 4 soal (slide 13)
- Efek hover pada skema harmoni dan psikologi warna

## Cara menjalankan
1. Unduh atau clone repositori ini.
2. Buka folder di VS Code.
3. Klik kanan `index.html`, pilih **Open with Live Server**.
   Atau klik dua kali `index.html` untuk membukanya langsung di browser.

Navigasi: tombol Sebelumnya/Berikutnya, panah keyboard, atau geser layar di HP.

## Struktur file
- `index.html`: isi semua slide
- `style.css`: tampilan dan transisi
- `script.js`: navigasi, mixer, pengecek kontras, kuis
